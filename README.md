# Kemas Terukur

Independent bilingual Vijeron site at `https://kemas.vijeron.com/`.

## Build

```powershell
python build.py
python check.py
```

`dist/` is committed for a Cloudflare Pages Git deployment. Set framework preset to **None**, leave the build command empty, and use `dist` as the output directory.

## Editorial and calculations

The eight guides are original Indonesian and English explanations. Source links support general principles; they do not imply endorsement or copy carrier rates. The dimensional-weight tool requires a user-provided divisor and displays a comparison, not a guaranteed billed weight. The box-fit tool checks rectangular geometry and optional right-angle rotations; it does not certify safe packaging.

GA4 measurement ID `G-79X7K7H4MJ`, AdSense publisher `ca-pub-6180580801533680`, Funding Choices, consent defaults, `ads.txt`, canonicals, reciprocal hreflang, JSON-LD, sitemap, robots and security headers are generated by `build.py`.

To correct content, edit `content.py`, rebuild, run checks and push. No product inputs are sent to Vijeron servers; GA4 tool events contain only the tool name and page language.
